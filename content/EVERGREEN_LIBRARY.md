# FutureHer — Evergreen Library (100 Core Topics)

**Parent manual:** `../FUTUREHER_CONTENT_INTELLIGENCE.md`  
**Status:** Core curriculum database (v1.0)  
**Rule:** Quality, trust, long-term value over virality.  
**Refresh law:** Update tool names; keep principles. Psychology supports — never headlines.

### How to use

1. Pick from Problem Bank first; match to a Topic ID below.  
2. Copy `../templates/TOPIC_CARD.md` into the episode folder.  
3. Fill Episode Brief → script → pyramid.  
4. After publish, update **Status** and evergreen notes in Sheets mirror.

### Field key (every topic)

`Aud` Audience · `Prob` Problem · `Out` Desired outcome · `Intent` Search intent · `E` Evergreen 1–10 · `Mon` Monetisation · `Prod` Digital products · `CTA` Recommended CTA · `Series` · `Shorts` · `DL` Download · `NL` Newsletter · `Pod` Podcast

**Pillars:** AF AI Fluency · CA Career Armor · MS Money Systems · BM Build Mode · SP Soft Power · MO Mind OS  
**Templates:** A Educational · B Money · C Career · D Relationships · E Stories  
**Lang priority:** ordered subtitle/community languages after EN
