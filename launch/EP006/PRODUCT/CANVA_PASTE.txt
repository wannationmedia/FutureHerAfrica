── PAGE 4: RTCCE at a glance ──
Teach: Role: who should AI act as. Task: the deliverable in one verb phrase. Context: facts it must know. Constraints: length, tone, format, what to avoid. Example: a tiny sample of the shape you want. That is a forever prompt.




── PAGE 5: Fill-in prompt builder ──
Teach: Write each line once. Paste into any assistant.
Prompt 1: ROLE — Act as a…
Prompt 2: TASK — Create / rewrite / summarise…
Prompt 3: CONTEXT — Facts it must know…
Prompt 4: CONSTRAINTS — Length, tone, avoid…
Prompt 5: EXAMPLE — Start like this / shape like this…
☐ My Task uses a clear verb (rewrite, summarise, draft, outline)
☐ I added at least one constraint (words, no buzzwords, format)
☐ I included a tiny example of the shape I want


── PAGE 6: Workplace examples ──
Teach: Steal the structure. Replace the facts with yours.


[Email rewrite] ROLE: Clear workplace communicator. TASK: Rewrite this email. CONTEXT: [paste facts]. CONSTRAINTS: 120 words, warm SA professional tone, no buzzwords. EXAMPLE: Start with the decision, then the ask.
[Meeting summary] ROLE: Reliable note-taker. TASK: Summarise these notes into decisions, owners, and next steps. CONTEXT: [paste]. CONSTRAINTS: bullets only, no invented names. EXAMPLE: Decision — Owner — Due.
[Lesson / training outline] ROLE: Practical adult educator. TASK: Outline a 20-minute lesson. CONTEXT: audience and outcome. CONSTRAINTS: three sections max, plain English. EXAMPLE: Hook · Skill · Practice.

── ACTION SHEETS ──
1. Rewrite your vaguest prompt with a clear Task verb (5 min) — Help with work becomes rewrite / summarise / draft.
2. Add one hard constraint (3 min) — Example: 120 words max, no buzzwords.
3. Add a one-line example of the shape you want (3 min) — Show the opening or bullet pattern.
4. Run the full RTCCE on one real work task (12 min) — Compare against your old vague prompt.
5. Save the winner in Forever Prompts (3 min) — Notes folder title: Forever Prompts.
6. Rate the result 1–5 and note what to tighten (2 min) — Constraints usually fix fluff.
