## 0. Purpose

This manual is the **editorial brain** of FutureHer.

It turns audience problems into a self-improving curriculum that can feed **years** of connected content across YouTube, Shorts, Reels, community, newsletter, blog, podcast, downloads, and premium products.

### What this engine must never do

- Chase trends as curriculum  
- Publish noise to “stay active”  
- Sacrifice trust for clicks  
- Invent problems the audience did not have  
- Skip Limpopo / South African reality for generic global advice  

### What this engine always does

- Starts from a real problem sentence  
- Maps one idea · one skill · one action  
- Atomizes one master into a full Content Pyramid  
- Feeds unused questions back into the Problem Bank  
- Improves topic ranking from retention, completion, and member outcomes  

**North star**

> She should never finish a FutureHer lesson and wonder, “What do I do now?”  
> And FutureHer should never finish a quarter and wonder, “What do we teach next?”

## 1. Operating Philosophy

### 1.1 Three intelligence layers

| Layer | Metaphor | Job |
|---|---|---|
| **Recommendation** | YouTube algorithm | Surface the next most useful lesson for *this* woman, at *this* stage |
| **Research desk** | Media company | Score demand, intent, evergreen strength, and SA relevance before filming |
| **Behaviour lab** | Behavioural science | Design actions she can complete under load-shedding, data cost, and real life |

### 1.2 Evergreen over trends

| Allowed | Forbidden as curriculum |
|---|---|
| Use a trend as *packaging* for an evergreen skill | Build the lesson around a dying meme or app fad |
| Update a core topic when tools change | Replace the library every quarter |
| Name current tools inside timeless principles | Teach tool buttons without a transferable skill |

**Rule:** If a topic will not still help a woman in three years (with a light refresh), it is not Core Library material. Park it as Seasonal / News Desk.

### 1.3 Self-improving loop

```
Audience problem
    → Topic Card scored
    → Episode Brief + 8-min master
    → Content Pyramid distributed
    → Signals collected (retention, comments, completions, product clicks)
    → Problem Bank + Evergreen scores updated
    → Better next topic selected
```

Nothing is “done” after publish. Every episode teaches FutureHer what to teach next.

## 2. Content Database System

### 2.1 Master objects

| Object | Definition | Home |
|---|---|---|
| **Category** | Broad subject cluster (AI, Money, Limpopo…) | §3 |
| **Topic Card** | One teachable unit with full metadata | `content/EVERGREEN_LIBRARY.md` + `templates/TOPIC_CARD.md` |
| **Problem Sentence** | Her words, not our title | Problem Bank |
| **Episode** | Filmed/published instance of a Topic Card | Drive `03_Episodes/` |
| **Pyramid Pack** | All derivatives of one master | Recycling + Community packs |
| **Signal Log** | Performance → ranking updates | Sheets / Analytics SOP |

### 2.2 Mandatory Topic Card fields

Every future topic — Core or Seasonal — must contain:

| Field | Meaning |
|---|---|
| **Audience** | Situation, not stereotype (e.g. “employed Limpopo professional with phone-only AI access”) |
| **Problem** | Exact spoken fear / friction |
| **Desired outcome** | What she can do or decide after the lesson |
| **Search intent** | Informational / How-to / Comparison / Local / Career / Fear-relief |
| **Evergreen score** | 1–10 (see §2.3) |
| **Monetisation opportunities** | Ethical path: ads / affiliate / entry product / course / sponsor *type* |
| **Digital products** | Named or named-pattern product that fits the ladder |
| **Recommended CTA** | One primary CTA only |
| **Suggested series** | `FutureHer · [Series]` |
| **Related Shorts** | 5 hook promises |
| **Related downloads** | Free worksheet / checklist / prompt pack |
| **Related newsletter** | Forward Notes angle |
| **Related podcast** | Audio episode angle / companion title |

Plus system fields:

| Field | Values |
|---|---|
| Topic ID | `T001`–`T100` (Core) · `S###` (Seasonal) · `P###` (Problem-Bank draft) |
| Category | From taxonomy §3 |
| Pillar | AI Fluency / Career Armor / Money Systems / Build Mode / Soft Power / Mind OS |
| CapCut template | A–E |
| Language priority | EN + ranked SA languages |
| Status | `IDEA` / `SCORED` / `BRIEFED` / `PRODUCED` / `LIBRARY` / `REFRESH` |
| Last refreshed | YYYY-MM |

### 2.3 Evergreen score model

Score = average of five dimensions (1–10):

| Dimension | High when… |
|---|---|
| **Durability** | Skill still matters in 3–5 years |
| **Transfer** | Works across tools/apps with minor refresh |
| **Audience breadth** | Helps more than one micro-niche |
| **Repeat demand** | Recurring in comments, polls, search |
| **Dignity fit** | Teachable without shame, hype, or false promises |

| Band | Action |
|---|---|
| **9–10** | Core Library — produce early, refresh lightly |
| **7–8** | Strong Core — schedule in quarterly arcs |
| **5–6** | Conditional — only if Problem Bank demand is high |
| **≤4** | Seasonal / skip — do not clog the library |

**Hard filters (any fail = do not Core-list)**

- [ ] Can become one idea / one skill / one action  
- [ ] SA / Africa relevant without caricature  
- [ ] Not medical, legal, or investment advice theatre  
- [ ] Phone-possible action exists where audience is phone-first  
- [ ] Trust intact if this is the only video she ever watches  

### 2.4 Topic selection algorithm (editorial recommendation)

When choosing the next episode, rank candidates:

```
Priority =
  (Problem recurrence × 3)
+ (Evergreen score × 2)
+ (Pillar balance need × 2)
+ (Series arc continuity × 1.5)
+ (Monetisation natural fit × 1)
+ (Language / Limpopo strategic weight × 1)
− (Recent duplicate penalty)
− (Trend-only penalty)
```

**Programming rule (unchanged):** Problem Bank first. Trends second. Ego never.

## 4. Content Pyramid

One master topic becomes a **connected product system**, not a pile of posts.

```
                    ┌─────────────────────┐
                    │  1 Long-form video  │  ← master classroom
                    └──────────┬──────────┘
           ┌───────────────────┼───────────────────┐
           ▼                   ▼                   ▼
     5 YouTube Shorts    IG Reels (best 3)   FB Reels (same 3)
           │                   │                   │
           └─────────┬─────────┴─────────┬─────────┘
                     ▼                   ▼
              Community Post        Newsletter (Forward Notes)
                     │                   │
                     ▼                   ▼
               Blog Article  ←──→  Podcast (clean audio)
                     │
                     ▼
              Free Download (worksheet / checklist / prompts)
                     │
                     ▼
           Premium Product (entry → core → membership)
```

### 4.1 Connection rules

| From | Must point to |
|---|---|
| Short / Reel | Full lesson on YouTube |
| Community post | Episode + challenge action |
| Newsletter | Watch link + community question |
| Blog | Embedded/linked video + download |
| Podcast | “Worksheet in show notes / community” |
| Free download | Soft CTA to challenge / entry product |
| Premium product | Built from proven Core Topics only |

**One primary offer per pyramid.** Secondary mentions stay soft.

### 4.2 Pyramid checklist (per episode)

- [ ] Long-form published (8-Minute Forward Format)  
- [ ] 5 Shorts scheduled across the week  
- [ ] 3 IG Reels + 3 FB Reels  
- [ ] Community post (question or challenge)  
- [ ] Forward Notes issued  
- [ ] Blog / LinkedIn article live  
- [ ] Podcast audio exported + published  
- [ ] Free download linked  
- [ ] Premium path noted (even if “none this week”)  
- [ ] Problem Bank updated from comments  

Use: `operations/RECYCLING/ONE_SCRIPT_MANY_OUTPUTS.md` + `templates/COMMUNITY_PACK.md` + `templates/RECYCLING_PACK.md`.

### 4.3 Pyramid naming

```
Topic ID:     T014
Slug:         phone-ai-without-laptop
Master:       FH_YYYYMMDD_PhoneAIWithoutLaptop
Shorts:       FH_Shorts_01..05
Reels:        FH_REEL_01..03
Download:     FH_DL_PhoneAI_Checklist
Product seed: FH_PRODUCT_AI_CalmFluency (if ladder match)
```

## 5. Community Intelligence — Problem Bank OS

Audience problems are the raw ore. Content is the refined metal.

### 5.1 Intake sources (mandatory scan list)

| Source | What to capture | Cadence |
|---|---|---|
| YouTube comments | Exact question phrases | 2×/week skim · Fri deep |
| Community tab replies | Poll losers + winners | After each poll |
| Email replies (Forward Notes) | Private fears she won’t post | Weekly |
| Facebook Group threads | Longer pain narratives | 2×/week |
| WhatsApp Ask Forward | Voice-note summaries → text problem sentences | Daily light / Fri deep |
| Polls | Demand ranking between 2–4 topic options | Weekly |
| Forward Hour / Q&A | Myths + stuck points | Per live |
| Google / YouTube search trends | SA + “for women” + career/AI/money modifiers | Monthly |
| Recurring questions | Same problem ≥3 times | Instant promote |

### 5.2 Problem sentence standard

Write problems in **her words**:

| Weak (topic voice) | Strong (her voice) |
|---|---|
| AI tools overview | “I’m scared AI will replace my job.” |
| Budgeting tips | “My salary disappears before month-end.” |
| Personal branding | “I work hard but nobody notices me.” |

**Tests** (from `templates/PROBLEM_BANK.md`)

- [ ] Sounds spoken out loud  
- [ ] One idea / one skill / one action possible  
- [ ] Fits 8-minute template  
- [ ] Not medical/legal advice territory  

### 5.3 Problem → Topic promotion path

```
Raw note
  → Problem Bank row (her words)
  → Recurrence count + urgency × teachability rank
  → Draft Topic Card (P###)
  → Score evergreen + SA filters
  → Promote to Core (T###) or Seasonal (S###)
  → Episode Brief when scheduled
```

### 5.4 Friday Community Intelligence ritual (15–25 min)

1. Skim YT / WA / FB / email  
2. Add new problem sentences  
3. Increment recurrence tallies  
4. Rank top 10 unanswered  
5. Pre-select next batch episode  
6. Park research-heavy items  
7. Update Evergreen scores if signals contradict assumptions  

### 5.5 Signal types that rewrite the library

| Signal | Editorial response |
|---|---|
| High CTR, low retention | Fix hook honesty or pacing — do not clone the title trick |
| High retention + many “how do I…?” comments | Spin sequel Topic Cards immediately |
| Download claimed, action not done | Simplify action; phone-first rewrite |
| Same question in 3 languages | Raise multilingual priority (§8) |
| Anger / distrust comments | Pause monetisation; run trust repair episode |
| Member Forward Wins on a skill | Elevate topic evergreen score + build product |

## 8. Multilingual Strategy

FutureHer is a multilingual educational media company.  
The mark stays **FutureHer**. Access expands through language layers.

### 8.1 Language tags (every major topic)

Tag each Topic Card for:

| Code | Language |
|---|---|
| `EN` | English (primary production language) |
| `VE` | Tshivenda |
| `TS` | Xitsonga |
| `NSO` | Sepedi |
| `ZU` | isiZulu |
| `SS` | siSwati |

Fields on card:

- **Production language** (default `EN`)  
- **Subtitle priority** (ordered list)  
- **Community welcome languages** (WA Limpopo Circle)  
- **Full dub / VO priority** (rare; earned)  

### 8.2 Layered access model

| Layer | What ships | When |
|---|---|---|
| L0 | Clear SA English VO + on-screen English | Every episode |
| L1 | Subtitles: EN always | Every episode |
| L2 | Subtitles: priority African language(s) | Top evergreen + high local demand |
| L3 | Community voice notes in local language | WhatsApp Limpopo Circle weekly |
| L4 | Partial VO dub / bilingual host segments | After retention proves demand |
| L5 | Full local-language remakes | Flagship Core Topics only |

Do not delay English masters waiting for perfect dubs. Ship readiness first; deepen access next.

### 8.3 What to translate first (priority score)

```
Translate Priority =
  (Audience demand signals × 3)
+ (Educational impact / life-stakes × 3)
+ (Evergreen score × 2)
+ (Phone-first rural reach × 2)
+ (Safety / scam prevention value × 2)
+ (Series binge potential × 1)
− (High jargon / tool-UI fragility)
```

### 8.4 First-wave translation queue (recommended)

Produce **EN master → EN+NSO or EN+VE/TS subtitles** first for Limpopo gravity, then ZU/SS for national scale.

| Rank | Topic themes | Why first |
|---|---|---|
| 1 | Online scams & cyber safety | High harm prevention; trust brand |
| 2 | Phone-first AI / digital literacy | Broad access; rural constraint |
| 3 | Money basics (salary, saving, airtime/data) | Universal stakes; dignity |
| 4 | Job hunting on a phone | Career mobility |
| 5 | Limpopo opportunities & local skills | Place loyalty; belonging |
| 6 | Confidence / communication scripts | Soft Power travels by voice note |
| 7 | Motherhood + skills return | FB cohort; high shareability |
| 8 | Student study systems | Youth Month + matric cycles |

Defer full translation of rapidly changing tool UI tours until principles cut is stable.

### 8.5 Community language practice

- WhatsApp **Limpopo Circle:** English + Sepedi / Tshivenda / Xitsonga welcome  
- Facebook: longer EN with local phrases where natural  
- Never shame mixed-language speech  
- Keep brand microcopy English for consistency (`Welcome forward.` / `Ready for what’s next.`)  
- Local greetings allowed in community spaces

### 9.2 System prompt (company standard)

```
You are Forward Desk, the internal FutureHer Content Intelligence Assistant.

Company: FutureHer — premium multilingual educational media for South African /
African women (Limpopo → SA → Africa).

Editorial promise: readiness, not noise.
Law: One idea · One skill · One action today (<30 minutes).
```

**D — Script**

**F — SEO**

```

```

**G — Engagement**


**H — Recycling**

```

```

**I — Quality control**


## 10. Quality, Trust & Anti-Virality Laws

### 10.1 Trust > reach

| If you must choose… | Choose |
|---|---|
| Clever hook vs honest hook | Honest |
| Trend packaging vs clear skill | Clear skill |
| Aggressive CTA vs teach-first | Teach-first |
| More episodes vs better library | Better library |

### 10.2 Quality bar (every pyramid)
