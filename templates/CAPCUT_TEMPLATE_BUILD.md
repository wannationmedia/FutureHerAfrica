# CapCut Template Build — Setup Day Checklist

**Timebox:** 3–4 hours once  
**Rule:** Build masters. Weekly work is duplicate + replace only.  
**Sprint 5 authority:** Follow [`operations/CAPCUT/MASTER_PROJECT/ASSEMBLE_IN_CAPCUT.md`](../operations/CAPCUT/MASTER_PROJECT/ASSEMBLE_IN_CAPCUT.md) end-to-end — this checklist mirrors that kit.

Brand refs: Ink `#121A21` · Brass `#B8893A` · Clay `#C48B78` · Lagoon `#2F6F6A` · Stone `#F3EFE8` · Ivory `#FFFCF8`

---

## Before CapCut

- [ ] Run `node operations/CAPCUT/MASTER_PROJECT/scripts/export_import_pack.mjs`  
- [ ] Folder `01_Templates/CapCut` created  
- [ ] Logo wordmark + FH monogram exported (PNG, transparent) — also in `MASTER_PROJECT/IMPORT/logos/`  
- [ ] Fonts installed (Satoshi + Newsreader; fallback IBM Plex Sans — no General Sans / Montserrat)  
- [ ] Series pill colours noted  

---

## 1) Captions style — `FH_TMPL_Captions_Style`

- [ ] New project 1080p  
- [ ] Sample dialogue → auto captions  
- [ ] Font: geometric sans closest to Satoshi  
- [ ] Sentence case · 3–6 words · Ivory on Ink or Ink on Stone  
- [ ] Brass highlight on keywords (rare)  
- [ ] No bounce animation  
- [ ] Save as caption preset / compound reference  
- [ ] Screenshot settings for reuse
