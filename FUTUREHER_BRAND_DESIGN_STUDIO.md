# DELIVERABLE 2 — Logo System

## 2.1 Concept — Horizon

Two elements only:

1. **Wordmark:** `FutureHer` in Satoshi Medium / Semibold  
2. **Horizon arc:** minimal rising curve — forward motion, dawn, next step  

**Metaphor:** She is not waiting for the future. She is moving toward the horizon.

**Never in the mark:** sun emoji, face silhouette, crown, butterfly, Venus symbol, lashes, heels, kente fill, pink “Her”.

## 2.2 Geometry construction

| Element | Spec |
|---|---|
| Wordmark tracking | −1% optical |
| Wordmark case | Title case as `FutureHer` (F and H capital; no space) |
| Arc | Single open stroke; ends softly rounded |
| Arc stroke weight | ≈ 1/12 of icon width (icon); ≈ 8–10% of wordmark cap-height (lockup) |
| Arc motion | Rising left → right; implied 12–18° |
| Arc position (primary) | Centred above wordmark with clear air = 0.35× cap-height of **H** |
| Optical box (icon) | Square; arc optically centred, not mathematically jammed to edges |
| Clear space | Cap-height of **H** on all sides of full lockup |
| Minimum width | 120px digital · 30mm print |
| Minimum icon | 32px (simplify: no Brass micro-dot below 48px) |

## 2.3 Logo versions (mandatory exports)

| Asset ID | Treatment | Use |
|---|---|---|
| `FH_Logo_Primary_Ink` | Ink wordmark + Brass arc on Stone/Ivory | Default light |

## 2.4 Monogram

| Spec | Value |
|---|---|
| Letters | **FH** Satoshi Bold |
| Container | Soft square; corner radius = **16%** of side |
| Inner padding | **22–25%** of side |
| Light | Ink on Stone; optional Brass 2px bottom accent rule |
| Dark | Ivory on Ink |
| Brass solid | Ivory FH on Brass — badges only |
| Never | Circle with photo; outlined neon FH; FH with sparkles |

## 2.5 Series lockup (secondary)

```
FutureHer · Money
```

- Satoshi Medium  
- Interpunct `·` with hair space  
- Series word in series accent OR Mist for Stories  
- Horizon arc optional above full line only when space ≥ 320px wide  

## 2.6 App icon (1024×1024)

| Layer | Spec |
|---|---|
| Background | Ink `#121A21` (or Ink Depth gradient §4.9) |
| Symbol | Ivory horizon arc **or** Ivory FH monogram |
| Optional | Single Brass micro-dot at rising end of arc (1 element max) |
| Safe zone | 20% inset adaptive |
| Forbidden | Photo faces, glitter, multi-gradient rainbow, text paragraphs |

## 2.7 Logo misuse (absolute bans)

- Neon outline / glow / drop shadow as identity  
- Busy background without solid panel  
- Rotating arc into a “smile”  
- Recolouring “Her” pink or Clay  
- Stretching, skewing, outline stroke as style  
- Tagline inside the logo master file  
- Pattern fill of the wordmark  

## 2.8 File delivery formats

For every logo ID: **SVG** + **PNG @1x/@2x** + **PDF** (print pack).  
App: PNG 1024 + platform size set.  
Favicon: `.ico` + SVG.

# DELIVERABLE 3 — Icon System

## 3.1 Purpose

Icons support teaching — they never decorate for decoration’s sake. One icon = one concept.

## 3.2 Grid & geometry

| Spec | Value |
|---|---|
| Artboard | 24×24 px master (scale to 16 / 20 / 32 / 48) |
| Keyline | Live area 20×20 inside 24 box (2px padding) |
| Stroke | **1.75px** at 24px (optical); round caps + round joins |
| Corner radius | 1.5–2px on rectangles |
| Angles | Prefer 0° / 90° / 45°; avoid noisy diagonals |
| Optical balance | Icons must sit on same visual weight as neighbours |
| Style | Outlined (default) · Duotone (stroke + 20% fill of series accent) for feature lists |

## 3.3 Colour rules

# DELIVERABLE 5 — Typography System

## 5.1 Principles

Phone-first readability · Sentence case · Restrained titles · Max two families per frame · Serif display at most once per video.

### 5.1a Multilingual / bilingual on-screen craft (L1–L2)

| Rule | Spec |
|---|---|
| Master language on-screen | Clear SA English (production language) |
| Burned-in captions | English always (Foundation L1) |
| L2 African-language subtitles | Prefer YouTube/platform subtitle track — do not bake dual language into burned captions unless flagged as bilingual lesson |
| Bilingual burned captions (rare) | English line primary (Satoshi Medium); secondary language line below in Satoshi Regular, 85% size, text.secondary; max 2 lines total; increase hold time +20% |
| Series pills / meta | Remain English for brand consistency |
| Wordmark | Always **FutureHer** — never translated in the mark |
| Community voice notes | Local languages welcome; brand microcopy stays English |

## 5.2 Families

| Role | Font | Source | Weights | Use |
|---|---|---|---|---|
| Primary | **Satoshi** | Fontshare | 400–700 | UI, captions, thumbnails, body, CapCut |
| Secondary / fallback | **IBM Plex Sans** | Google Fonts | 400–600 | Docs, Sheets, offline fallback |
| Display | **Newsreader** | Google Fonts | 500–600 | Title cards, covers, brand films |
| Alt display | **Fraunces** | Google Fonts | 500–600 | Softer covers — never mix with Newsreader in one asset |
| Subtitle / workbook section | **Source Serif 4** | Google Fonts | 400–600 | Article/workbook section titles |
| Canva emergency | **Plus Jakarta Sans** | Canva | 500–700 | Only if Satoshi upload unavailable |

## 5.3 Type scale

| Token | Desktop | Mobile / Shorts | Font | Weight | Tracking | Leading |
|---|---|---|---|---|---|---|
| Display | 56–72px | 36–44px | Newsreader | 600 | −1% | 1.1–1.15 |
| H1 | 40–48px | 28–32px | Satoshi | 700 | −1% | 1.15 |
| H2 | 28–32px | 22–24px | Satoshi | 600 | 0 | 1.2 |
| H3 | 20–24px | 18–20px | Satoshi | 600 | 0 | 1.25 |
| Body | 16–18px | 15–16px | Satoshi/Plex | 400 | 0 | 1.45–1.55 |
| Subtitle | 18–20px | 16–18px | Source Serif 4 | 400 | 0 | 1.4 |
| Caption (video) | 18–22px | 28–36px Shorts | Satoshi | 500 | 0 | 1.25 |
| Meta / labels | 11–13px | 11–12px | Satoshi | 500 | +2% | 1.2 |
| Thumbnail title | — | optical ~64–84px @1280 | Satoshi | 700 | −1% | 1.05 |

## 5.4 Case & punctuation

1. Sentence case for nearly everything.  
2. ALL CAPS only for tiny meta: `SERIES · AI · STEP 02`.  
3. Thumbnail: max **4–6 words**.  
4. One question mark max if title is a true question.  
5. No exclamation forests.  
6. Em dash sparingly; prefer short sentences.

## 5.5 Platform stacks

| CapCut | Install Satoshi + Newsreader → System Fonts; fallback IBM Plex Sans |
| Canva Brand Kit | Upload Satoshi; Newsreader/Fraunces from library |

| Web | Satoshi (Fontshare) + Newsreader |
| Print ebook | Satoshi or Plex + Newsreader; embed fonts |

# DELIVERABLE 6 — Illustration System

## 6.1 Philosophy

Editorial · simple · teachable. Illustrations explain frameworks. They are not decoration dumps or AI fantasy posters.

## 6.2 Approved styles (only these three)

| Style ID | Description | Use |
|---|---|---|
| **FH_Illus_Line** | Thin stroke diagrams on Stone/Ink; Lagoon/Brass/Clay strokes | Frameworks, 2×2s, pathways |
| **FH_Illus_Flat** | Flat 2D shapes; limited palette (max 4 brand colours + Ivory) | Conceptual scenes, covers |
| **FH_Illus_Spot** | Small spot illustrations for ebook chapter openers | Products |

## 6.3 Illustration rules

| Rule | Spec |
|---|---|
| Stroke | Match icon system weight family |
| Palette | Brand colours only |
| People | Abstract / respectful; diverse SA/African presentation; no caricature |
| Backgrounds | Stone, Ivory, Ink — or transparent |
| Perspective | Flat or gentle isometric — never chaotic 3D chrome |
| Text in image | **Never** bake final titles into AI art; overlay real type |
| Lighting | Soft, even; consistent with photo grade |

## 6.4 Framework diagram vocabulary

| Diagram | Construction |
|---|---|
| Pathway | Horizontal steps 01–03; Brass connectors; Satoshi labels |
| Loop | Circular process; Lagoon stroke; one Brass “start” node |
| Stack | Vertical cards; Mist borders; Ink titles |
| 2×2 | Ink axes; four Stone cells; one accent cell max |
| Before / After | Two panels; Mist divider; no shocking red “FAIL” stamps |
| Script card | Stone card; Clay or Brass left rule 4px; quote in Satoshi |

## 6.5 Forbidden illustration looks

- Cyberpunk neon women / chrome goddess  
- Kente / tribal pattern as wallpaper  
- Uncanny plastic AI skin as hero  
- Mascot characters (unless future IP explicitly commissioned)  
- Glitter, stickers, comic speed lines  
- US skyline / generic handshake as “success”

# DELIVERABLE 9 — Motion Graphics Guide

## 9.1 Motion principles

| Principle | Spec |
|---|---|
| Pace | Confident, never frantic |
| Easing | Ease-in-out |
| Duration | **240–400ms** for UI / transitions |
| Kinetic type | Word or chunk reveal 120–180ms — **no bounce** |
| Logo | Arc draws once; wordmark settles; **stop** |
| Camera | 5–8% punch zoom on key lines only |
| Silence | On-brand; do not fill every cut with SFX |

## 9.2 Timing tokens

| Token | Duration |
|---|---|
| `fh.motion.fast` | 180ms |
| `fh.motion.base` | 280ms |
| `fh.motion.slow` | 400ms |
| `fh.motion.hold.idea` | 2.5–3.5s |
| `fh.motion.intro` | 6–8s |
| `fh.motion.outro` | 20–35s |
| `fh.motion.sting` | 1.2s (≤1.5s) |

## 9.3 Approved motion vocabulary

| Move | Spec |
|---|---|
| Dissolve | 280–400ms |
| Soft dip to Ink | 320ms |
| Card slide | 280ms horizontal |
| Underline reveal | Brass/Lagoon/Clay 240ms left→right |
| Diagram draw-on | Left→right / top→bottom 400–800ms |
| Number gentle count | Money template only |
| Fade up phrase card | Relationships 320ms |

## 9.4 Forbidden motion

Meme zooms · shake · spin logos · bounce easing · flash-cut default · sticker pop storms · 3D logo tunnels.

## 9.5 Lower thirds motion

Fade in 0.4s · hold ~4s · fade out 0.3s · Brass 2px top rule static.

## 9.6 Type on screen

Logo sting **always** pairs with Horizon arc completion (±3 frames).
