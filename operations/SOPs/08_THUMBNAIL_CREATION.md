# SOP 08 — Thumbnail Creation

**Owner:** Founder  
**Cadence:** Every episode  
**Estimated time:** 10 minutes  
**Host authority:** `brand/FUTUREHERAFRICA_AI_HOST_BIBLE.md`  
**Studio:** §8 (+ §8.8 host continuity)

---

## Objective

Create one readable, premium 1280×720 thumbnail from a locked template — face + 4–6 words + series pill + FH mark — using the **canonical FutureHerAfrica host** when the face layout is used.

---

## Inputs

- Canonical host thumbnail pose **or** strongest calm A-roll face (live founder)  
- Series accent (Lagoon / Brass / Ink / Clay / Mist)  
- Template: CapCut or Canva `FH_TMPL_Thumbnail_1280x720`  
- Reference lock: `launch/EP001/FH_EP001_Thumbnail.png`

## Output

PNG/JPG 1280×720 in `06_thumbnail/`

---

## Step-by-step checklist

- [ ] Duplicate thumbnail master (never redesign)  
- [ ] Drop face/frame into locked zone  
- [ ] **Face layout:** confirm EP001 squint test — same host, not a new woman  
- [ ] If generating a new host pose: `brand/FH_HOST_GENERATION_PROMPT.txt` § thumbnail fill + EP001 reference; reject identity drift  
- [ ] Write 4–6 word title (outcome language, sentence case)  
- [ ] Apply correct series pill colour  
- [ ] Place FH mark with clear space  
- [ ] No red arrows, shocked-face cliché, neon, collage  
- [ ] Export 1280×720  
- [ ] Preview at mobile stamp size — must still read  

**Object / illustration layouts** may omit a face — still use the locked template grid.

---

## ChatGPT assist (optional, 1 min)

> Give me 8 thumbnail text options, max 6 words, calm premium educational tone, no clickbait, for: [problem sentence]

Pick one. Do not workshop ten rounds.

---

## AI tools used

| Tool | Use |
|---|---|
| CapCut / Canva | Template duplicate + export |
| ChatGPT | Text options only |
| Host gen | Thumbnail pose only via Host Bible / generation prompt |

---

## Human review points

1. Readable at stamp size?  
2. Complements title — doesn’t duplicate the full title paragraph?  
3. Face = canonical EP001 host (when face layout)?  

---

## Quality-control checklist

- [ ] 1280×720  
- [ ] ≤ 6 words on image  
- [ ] Series pill correct  
- [ ] Brand colours only  
- [ ] Canonical host continuity (face layout)  
- [ ] Looks editorial, not influencer bait  

**Pass → SOP 09 SEO**
