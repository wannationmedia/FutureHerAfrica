# SOP 04 — Voice-over Production

**Owner:** Founder  
**Cadence:** Every episode  
**Estimated time:** 40 minutes

---

## Objective

Capture a clean, calm, intelligent founder performance (primary trust asset). Synthetic voice is rare exception only.

---

## Inputs

- `FACT-OK` script  
- Quiet room + phone/laptop mic  
- Consistent brand framing (shirt/background/light)

## Output

A-roll (+ optional screen/B-roll) in `03_footage/`

---

## Step-by-step checklist

### A. Default — founder voice

- [ ] Quiet room; long-form horizontal preferred  
- [ ] Mic 15–20 cm; soft daylight or one LED  
- [ ] Teleprompter: Docs big text / CapCut teleprompter / printed script  
- [ ] Slate: `FH [slug] take 1`  
- [ ] Prefer longer takes with pauses over 40 micro-clips  
- [ ] Record cold open separately if energy is better (optional)  
- [ ] Capture 3–5 B-roll only if essential  
- [ ] Screen-record demos in one pass  
- [ ] Backup files to episode `03_footage/`  

### B. CapCut cleanup (≤ 2 min)

- [ ] Voice enhance / denoise  
- [ ] Normalize loudness  
- [ ] Remove only obvious mouth clicks  

### C. Rare — CapCut TTS

Use only for accessibility alt cuts or emergency drafts. Never default channel voice.

- [ ] Test 10s first; rewrite shorter clauses  
- [ ] Do not fake “live teaching” if it breaks trust  

---

## AI tools used

| Tool | Use |
|---|---|
| CapCut Pro | Teleprompter (if used), enhance, denoise |
| ChatGPT | Optional: shorten script for breathability |

---

## Human review points

1. Do you sound like a mentor — not a radio ad?  
2. Is energy calm enough to rewatch at 1.0×?  

---

## Quality-control checklist

- [ ] Audible on phone speaker  
- [ ] No clipping / heavy room echo  
- [ ] SA English natural; no forced accent performance  
- [ ] Files named `FH_YYYYMMDD_Slug_Aroll`  
- [ ] Ready for CapCut edit  

**Pass → SOP 07 CapCut Editing** (and 05/06 only if visuals needed)
