# SOP 10 — Upload Workflow

**Owner:** Founder  
**Cadence:** Every episode  
**Estimated time:** 15–20 minutes (with SEO pack ready)

---

## Objective

Upload and schedule the entire week in one sitting using reusable Studio defaults and the upload pack — zero rewrite from scratch.

---

## Inputs

- Exports + thumbnail  
- Completed `operations/UPLOAD/MASTER_UPLOAD_PACK.md`  
- YouTube Studio defaults (end screen, category)

## Output

Long-form + Shorts + Reels scheduled; pin comment ready; tracker → `SCHEDULED`

---

## Step-by-step checklist

### YouTube long-form

- [ ] Upload export  
- [ ] Custom thumbnail  
- [ ] Paste title / description / tags  
- [ ] Playlist  
- [ ] End screen = channel default (Subscribe + 2 videos)  
- [ ] Cards: 1 mid-video related lesson (skip if behind)  
- [ ] Captions: SRT if available, else check auto  
- [ ] Schedule consistent weekly slot  
- [ ] Prepare pinned comment = community question  

### YouTube Shorts (5)

- [ ] Upload 5  
- [ ] Hook titles  
- [ ] Schedule 1/day Tue–Sat (or Mon–Fri)  
- [ ] Minimal hashtags  
- [ ] Point to long-form where allowed  

### Instagram + Facebook Reels (3)

- [ ] Upload via Meta Business Suite  
- [ ] Caption: hook + “Full lesson on YouTube — FutureHer”  
- [ ] Same 3 files to IG + FB  
- [ ] Schedule Wed/Fri (and one midweek optional)  
- [ ] Cover = first clear face frame  

### Files / tracker

- [ ] Exports remain in episode folder  
- [ ] CapCut project linked/noted  
- [ ] Episode Tracker → `SCHEDULED`  
- [ ] Run QC gate (`operations/QC/PRE_PUBLISH_QUALITY_GATE.md`) before first public go-live  

---

## AI tools used

| Tool | Use |
|---|---|
| YouTube Studio | Schedule + metadata |
| Meta Business Suite | Reels schedule |
| ChatGPT | Only if upload pack fields still empty |

---

## Human review points

1. Is the week fully scheduled so you need ≤ 5 min/day after this?  
2. Pin comment actually invites thinking?  

---

## Quality-control checklist

- [ ] Nothing left as “draft forever” unintentionally  
- [ ] End screens/cards not broken  
- [ ] No copyright claim surprises (CapCut music/stock only)  
- [ ] Tracker updated  

**Pass → SOP 11 Community Posts + Recycling pack paste**
