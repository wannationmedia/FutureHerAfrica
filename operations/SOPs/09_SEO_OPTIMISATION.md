# SOP 09 — SEO Optimisation

**Owner:** Founder  
**Cadence:** Every episode  
**Estimated time:** 10 minutes

---

## Objective

Make the episode findable by the woman with the problem — using her language — without keyword spam.

---

## Inputs

- Script header + problem sentence  
- YouTube autocomplete sniff  
- Upload pack: `operations/UPLOAD/MASTER_UPLOAD_PACK.md`

## Output

Title · description · tags · chapters · hashtags · playlist assignment (filled pack)

---

## Step-by-step checklist

- [ ] Type problem into YouTube search → note autocomplete phrasing  
- [ ] Pick title from title templates (outcome + truth; + SA when natural)  
- [ ] Ensure thumbnail text ≠ full title duplicate  
- [ ] Fill description block 1 (first 2 lines): problem + promise + Forward Collective CTA  
- [ ] Paste chapters from script section times  
- [ ] Paste standard links block (WhatsApp / newsletter / challenge)  
- [ ] Select 8–15 tags from tag bank + episode-specific phrases  
- [ ] Assign series playlist  
- [ ] Category: Education · Language: English (South Africa)  
- [ ] Shorts titles = hook phrases from `[S1]`–`[S5]`  
- [ ] Minimal hashtags (`#FutureHer` + 1 topic)  

---

## AI tools used

| Tool | Use |
|---|---|
| ChatGPT | Title variants + chapter labels from script |
| YouTube search | Autocomplete truth |

Prompt:

> Rewrite this problem as 5 YouTube titles under 70 characters, calm educational tone, no ALL CAPS, optional South Africa when natural: [problem]

---

## Human review points

1. Would she understand the click in one second?  
2. Is this searchable truth — or clever nonsense?  

---

## Quality-control checklist

- [ ] Title uses her words  
- [ ] Chapters present  
- [ ] No tag stuffing  
- [ ] Playlist set  
- [ ] Description CTA soft, not begging  

**Pass → SOP 10 Upload Workflow**
