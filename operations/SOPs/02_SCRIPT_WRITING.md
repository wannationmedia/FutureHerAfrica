# SOP 02 — Script Writing

**Owner:** Founder  
**Cadence:** Every episode  
**Estimated time:** 30 minutes (hard stop)

---

## Objective

Produce a speakable 8-Minute Forward Format script with Shorts markers and recycling hooks — conversational SA English, premium teacher tone.

---

## Inputs

- Completed episode brief + research bullets  
- Template: `templates/SCRIPT_8MIN.md`  
- CapCut template choice (A–E)

## Output

Filled script with `[S1]`–`[S5]` markers + Idea / Skill / Action header

---

## Step-by-step checklist

- [ ] Duplicate `SCRIPT_8MIN.md` into episode folder  
- [ ] Fill Idea / Skill / Action **before** prose  
- [ ] ChatGPT draft assist (optional): paste brief → ask for cold open in SA English, max 80 words, no hype  
- [ ] Write hook (0:00) in her language  
- [ ] Write SA story beat (authentic, not caricature)  
- [ ] Explain problem simply  
- [ ] Teach skill in ≤ 3 steps; name **one** framework max  
- [ ] Psychology beat (why it works / remove shame) — support only  
- [ ] One action today (single step)  
- [ ] Community question (meaningful)  
- [ ] Community challenge line  
- [ ] Next episode preview (one sentence)  
- [ ] Mark `[S1]`–`[S5]` on strongest standalone beats  
- [ ] After master script: rewrite each Short via `templates/SHORTS_SCRIPT.md` (HOOK → REFRAME → VALUE → ACTION)  
- [ ] End every Short with locked sign-off: *One step today. A different future tomorrow.*  
- [ ] Read aloud once; cut any sentence you trip on  
- [ ] Hard stop at 30 minutes (Shorts rewrite can use Stage 6B timebox)  

---

## AI tools used

| Tool | Use |
|---|---|
| ChatGPT | Cold open options, clarity rewrite, Shorts formula rewrite (`operations/SHORTS/SHORTS_ENGINE.md`) |
| Cursor | Keep script in repo/episode folder if preferred |

**Rule:** AI drafts. Founder voice decides final lines.

---

## Human review points

1. Would you say this out loud to a smart friend in Polokwane or Joburg?  
2. Is there exactly one action?  
3. Any American hype cadence to delete?  

---

## Quality-control checklist

- [ ] Idea / Skill / Action filled  
- [ ] ≤ 3 teaching steps  
- [ ] `[S1]`–`[S5]` present  
- [ ] Affiliate/tool mentions only if taught for real  
- [ ] No therapy substitute language  
- [ ] Ready for fact check  

**Pass → SOP 03 Fact Checking**
