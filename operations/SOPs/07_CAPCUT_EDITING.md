# SOP 07 — CapCut Editing

**Owner:** Founder  
**Cadence:** Every episode  
**Estimated time:** 45 min long-form + 40 min Shorts/Reels = 85 minutes

---

## Objective

Assemble the week’s master video and vertical cutdowns by **duplicating** the correct CapCut template (A–E) and replacing media/text only — never redesigning.

---

## Inputs

- Footage in `03_footage/`  
- Chosen template A–E (`operations/CAPCUT/`)  
- Script with Idea / Skill / Action + `[S1]`–`[S5]`

## Output

- Long-form export `FH_YT_1080p`  
- 5 Shorts + 3 Reels exports  

---

## Step-by-step checklist

### 7A — Long-form (45 min)

- [ ] Duplicate correct master — **never edit master**: `FH_TMPL_A_Educational` · `FH_TMPL_B_Money` · `FH_TMPL_C_Career` · `FH_TMPL_D_Relationships` · `FH_TMPL_E_Stories` (see `operations/CAPCUT/`)  
- [ ] Rename `FH_YYYYMMDD_Slug`  
- [ ] Replace media slot-by-slot (hook → story → problem → skill → psych → action → CTA → preview)  
- [ ] Intro / outro / brand animation already present — leave locked  
- [ ] Auto captions → apply template caption style → fix SA names/words  
- [ ] Lower thirds only at name + framework  
- [ ] Confirm music bed −24 to −30 dB under voice  
- [ ] SFX ticks only on list steps  
- [ ] Fill outro Idea / Skill / Action text  
- [ ] Place CTA screen compound  
- [ ] Add markers `S1`–`S5`  
- [ ] Watch at 1.25× for errors  
- [ ] Export to `05_exports/`  

### 7B — Shorts + Reels (40 min)

**Engine:** `operations/SHORTS/SHORTS_ENGINE.md` · **Script form:** `templates/SHORTS_SCRIPT.md`

- [ ] Confirm each Short follows HOOK → REFRAME → VALUE → ACTION (~28–30s)  
- [ ] Duplicate `FH_TMPL_Shorts_9x16` ×5 (or multi-scene)  
- [ ] Paste / punch-in / re-VO to formula lines (not raw long-form dump)  
- [ ] Reframe vertical; eyes upper third  
- [ ] Burned captions; large type; max ~6 words/card  
- [ ] Subtle 5–8% zoom on hook + action; premium transitions only  
- [ ] End CTA: *One step today. A different future tomorrow.* + Full lesson on FutureHer  
- [ ] Export 5 Shorts  
- [ ] Best 3 → `FH_REEL_01..03` (same files OK for IG + FB)  
- [ ] Spot-check on phone speaker  


### Kill-switches (if behind)

- No custom keyframed zooms  
- No new fonts / music search  
- No grade experiments

1. Does it look like FutureHer without reading the title?  
2. Is pace calm — not frantic jump-cut anxiety?  

---

## Quality-control checklist

- [ ] Correct series template (A–E) used  
- [ ] Captions readable on phone  
- [ ] Intro ≤ 8s before value  
- [ ] Outro has Idea / Skill / Action  
- [ ] No meme shake / neon  
- [ ] Loudness comfortable  
- [ ] Markers exported as Shorts  

**Pass → SOP 08 Thumbnail → SOP 09 SEO → SOP 10 Upload**
