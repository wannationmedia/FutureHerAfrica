# SOP 14 — Affiliate Integration

**Owner:** Founder  
**Cadence:** As earned / when a tool is truly taught  
**Estimated time:** 20–40 minutes setup; ≤ 2 minutes per episode mention

---

## Objective

Earn from tools the audience already needs — without turning FutureHer into an affiliate landfill. Teach first. Recommend second. Disclose always.

---

## Inputs

- Tool you have tested or would personally use  
- Partner log: `07_Partners/affiliates`  
- Ethical fit rules from founding strategy

## Output

Approved affiliate entry + disclosure line + description link block + optional end-card mention rules

---

## Step-by-step checklist

### Approve partner (once)

- [ ] Does this solve a real curriculum problem?  
- [ ] Have you tested it (or deeply evaluated)?  
- [ ] Any harm risk (especially money/fintech)? If high → reject  
- [ ] Join program; save link + terms in Partner log  
- [ ] Write 2-sentence “why we recommend” note  
- [ ] Write standard disclosure line  

### Integrate into an episode (only when taught)

- [ ] Tool appears inside skill demo — not cold pitch  
- [ ] Verbal disclosure once  
- [ ] Description link under clear label  
- [ ] Max **one** primary affiliate focus per episode  
- [ ] Never recommend fear-based / get-rich products  

### Monthly hygiene (5 min)

- [ ] Links still work  
- [ ] Remove dead programs  
- [ ] Check disclosure still accurate  

---

## Standard disclosure (reuse)

> Some links may be affiliate links. If you buy through them, FutureHer may earn a commission at no extra cost to you. I only recommend tools I’d teach anyway.

---

## AI tools used

| Tool | Use |
|---|---|
| ChatGPT | Draft “why we recommend” + disclosure variants |
| Google Sheets | Partner log |

---

## Human review points

1. Would you recommend this with zero commission?  
2. Does the episode still teach if the link is removed?  

---

## Quality-control checklist

- [ ] Disclosure present (spoken or written where required)  
- [ ] Fit-first, not commission-first  
- [ ] Money partners extra-cautious  
- [ ] Partner log updated  
- [ ] Audience dignity protected  

**Pass → publish with description links**
