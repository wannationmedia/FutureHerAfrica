# Pre-Publish Quality Gate

**Use:** Before any long-form, Short, Reel, product, or sponsor deliverable goes public.  
**Timebox:** 60–90 seconds for weekly content · 10 minutes for products/sponsors  
**Rule:** Fail → fix that item only. Do not reopen creative direction.

---

## Episode / social gate

**Slug:** _______________  
**Date:** _______________

### Accuracy

- [ ] Hard claims fact-checked or softened (`FACT-OK`)  
- [ ] No fake stats / guaranteed money outcomes  
- [ ] Tool capabilities stated honestly  

### Clarity

- [ ] One idea, one skill, one action obvious  
- [ ] She knows what to do in < 30 minutes  
- [ ] No jargon without plain translation  

### South African relevance

- [ ] Context fits SA reality (cost, platforms, language, work culture)  
- [ ] Not blind US advice copy-paste  

### Accessibility

- [ ] Captions readable on phone  
- [ ] Audio clear on phone speaker  
- [ ] Thumbnail readable at stamp size  

### Professional language

- [ ] Calm mentor tone — not hype or shame  
- [ ] SA English natural  
- [ ] No slur / mocking of audience struggle  

### Ethical recommendations

- [ ] Advice dignifies her intelligence  
- [ ] Money/career claims responsible  
- [ ] Affiliates disclosed if present  
- [ ] Psychology is support, not diagnosis  

### Brand consistency

- [ ] Correct CapCut template A–E  
- [ ] Ink/Stone/Brass (or series accent) world  
- [ ] Intro/outro/captions look FutureHer  
- [ ] CTA = Forward Collective / subscribe — not begging  
- [ ] If AI/digital host face appears: matches EP001 canonical host (`brand/FUTUREHERAFRICA_AI_HOST_BIBLE.md`) — not a new woman  

### Copyright compliance

- [ ] CapCut/Canva/own media only (or known-safe license)  
- [ ] No unlicensed music  
- [ ] No stolen thumbnails / others’ content  

### YouTube / platform policy compliance

- [ ] No medical/financial forbidden claims  
- [ ] No harmful/dangerous instruction  
- [ ] Disclosure for paid/affiliate where required  
- [ ] Thumbnails not deceptive vs content  

### Final

- [ ] **PASS** — schedule/publish  
- [ ] **FAIL** — note fix: _______________________________
