# Content Recycling — One Script → Many Outputs

**Objective:** Maximise distribution from one 8-minute master with minimum founder effort.  
**Timebox:** 15 minutes inside weekly batch (drafts); schedule/paste later in ≤ 2 min slots.  
**Tool:** ChatGPT + this template (paste master script once).

---

## Golden rule

Finish the **YouTube master** first. Everything else is extraction — not new creative work.

## QC for recycled content

- [ ] Links work
