# FutureHer Shorts Engine

**Authority:** This is the quality system for every YouTube Short / Reel cutdown.  
**Benchmark:** SHORT S1 (EP001) — human, conversational, emotionally intelligent, practical, premium, South African, hopeful.  
**Template:** `templates/SHORTS_SCRIPT.md`  
**CapCut:** `FH_TMPL_Shorts_9x16` · 9:16 · burned captions · FutureHer palette only  
**Host:** `brand/FUTUREHERAFRICA_AI_HOST_BIBLE.md` — ONE canonical host when a face frame is used

---

## Feel (non-negotiable)

FutureHer Shorts must feel:

- Human  
- Conversational  
- Emotionally intelligent  
- Practical  
- Premium  
- South African  
- Hopeful  

**Ban:** generic motivational language · AI-assistant cadence · preach · lecture · shame · hustle hype

**Voice:** trusted older sister · intelligent mentor · approachable · never superior

---

## Formula (every Short · ~28–30s)

| Time | Beat | Job |
|---|---|---|
| 0–3s | **HOOK** | Validate a real emotion, fear, frustration, or ambition. Viewer feels understood immediately. |
| 3–10s | **REFRAMING** | Name the real problem. Replace fear with understanding. |
| 10–22s | **VALUE** | Teach ONE practical idea. One lesson. One concept. One takeaway. |
| 22–30s | **ACTION** | One thing they can finish today. Never vague motivation. |
| Final hold | **SIGN-OFF** | Official brand line + full-lesson CTA |

### Hook patterns (examples)

- "You're not behind."  
- "You're not too old."  
- "It's not your phone that's the problem."  
- "You don't need a degree to start."  
- "You're not dramatic."  

### Reframe pattern

Fear-language → real-problem language  
Example: *The real fear isn't AI. The real fear is wondering if there's still a place for you.*

### Value rule

Never overload. If you need a second tip, it belongs in the long-form lesson.

### Action rule

Specific · phone-first · under 30 minutes · completable today

## Episode workflow

1. Write long-form with `[S1]`–`[S5]` markers on strongest standalone beats.  
2. **Rewrite each Short to this formula** into `templates/SHORTS_SCRIPT.md` (do not ship raw long-form paste).  
3. Prefer punch-ins / re-VO from formula lines when master audio is too long or lecture-shaped.  
4. CapCut: duplicate `FH_TMPL_Shorts_9x16` ×5 → paste ranges → reframe → scale captions → end CTA with official sign-off.  
5. Export `FH_SHORT_01`…`05` · phone-speaker QC.  
6. Best 3 → Reels (`FH_REEL_01`…`03`).

### Roles of S1–S5

| # | Role | Beat source (typical) |
|---|---|---|
| S1 | Emotional hook | Cold open / validation |
| S2 | Problem reframe | Problem section |
| S3 | One-skill micro-lesson | Skill (compress to one idea) |
| S4 | Psychology / stuckness | Psych beat |
| S5 | Action today | Action card |

## Quality gate (pass / fail)

- [ ] Hook validates a real feeling in ≤ 3s  
- [ ] Reframe replaces fear with clarity  
- [ ] Exactly one practical takeaway  
- [ ] Exactly one today-action  
- [ ] Conversational SA English — sister, not lecturer  
- [ ] Official sign-off present  
- [ ] Full-lesson CTA present  
- [ ] Captions readable on phone  
- [ ] FutureHer palette + motion only  
- [ ] No generic motivation / AI-assistant tone  
- [ ] If a host face appears: EP001 squint test pass (same person)  

**Fail any → rewrite / regenerate before export.**
