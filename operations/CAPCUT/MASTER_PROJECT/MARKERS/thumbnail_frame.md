# Thumbnail frame markers

**Marker ID:** `THUMB_FRAME`  
**Default park:** `00:00:22:00` (mid-Hook) — move to best face frame after VO lands  
**Export:** Still → `FH_THUMB_{YYYYMMDD}_{Slug}` · 1280×720  
**Host:** Face stills must match `brand/FUTUREHERAFRICA_AI_HOST_BIBLE.md` (EP001 canonical host) when using AI / digital host

## Zone rules (overlay: `OVERLAYS/FH_Thumbnail_Zones_1280x720.svg`)

| Zone | Spec |
|---|---|
| Face | Left **or** right third — pick one side and keep consistent channel-wide · **same host as EP001** |
| Title | Opposite third · Satoshi Bold · max **4–6 words** · sentence case |
| Series pill | Top · one accent from series map |
| FH mark | Corner · clear space · never on teeth/eyes |
| Background | Soft `FH_Grade_Horizon` · Stone panel or negative space · **no collage** |

## CapCut path

1. Park playhead on `THUMB_FRAME` **or** import pre-generated `FH_Host_*_ThumbFace_*`  
2. Export frame / screenshot at full res (if from timeline)  
3. Duplicate `FH_TMPL_Thumbnail_1280x720`  
4. Drop face · replace title · set series pill colour  
5. Squint test vs `launch/EP001/FH_EP001_Thumbnail.png`  
6. Export PNG/JPG 1280×720  

## Weekly replace only

- Face still (canonical host continuity)  
- Title words  
- Series pill text/colour (from registry)
