## Universal locked elements (every A–E master)

| Element | Spec |
|---|---|
| Intro | 6–8s compound |
| Outro | 20–35s with Idea / Skill / Action slots |
| Brand animation | Horizon + wordmark |
| Caption style | Sentence case, 3–6 words, Ivory/Ink |
| Font system | Sans for UI/captions; serif only for rare title cards |
| Colour system | Ink/Stone base + series accent |
| Music style | Bed from favourites at −24 to −30 dB |
| Transition presets | 240–400ms ease only |
| Zoom animations | Subtle 5–8% punch on key lines (saved keyframes) — not shake |
| Lower thirds | Name / Framework / Series / Step |
| CTA screen | Subscribe + Forward Collective |
