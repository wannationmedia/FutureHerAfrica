# Digital Product Template — Standard Structure

**Rule:** Every FutureHer product uses this skeleton. Duplicate → fill → export.  
**Design file:** Canva master `FH_PRODUCT_MASTER` (create once)  
**Brand:** Ink / Stone / Brass · Satoshi + Source Serif/Newsreader · FH mark  
**Engine:** `scripts/generate-products.mjs` → `launch/EPxxx/PRODUCT/` (publication-ready; no placeholders)  
**Types:** see `PRODUCT_TYPES.md` · **Canva:** see `CANVA_EXPORT_SPEC.md` · **Email:** see `EMAIL_SEQUENCE_TEMPLATE.md`

---

## Required pages (never skip)

| # | Page | Purpose |
|---|---|---|
| 1 | **Cover** | Title, subtitle, FH mark, series accent |
| 2 | **Branding** | Who it’s for + promise + “Ready for what’s next.” |
| 3 | **Table of contents** | Scannable sections |
| 4 | **Workbook pages** | Frameworks, prompts, worksheets |
| 5 | **Action steps** | Numbered, timeboxed actions |
| 6 | **QR codes** | Forward Collective + related YouTube playlist |
| 7 | **Upsell page** | Soft next step (challenge / next product / community) |
| 8 | **Thank-you page** | Warm close + support email/WhatsApp |

---

## Page specs

### 1) Cover

- Title ≤ 8 words  
- Subtitle = outcome in one line  
- Accent bar matches pillar (Lagoon/Brass/Ink/Clay)  
- No stock collage chaos  

**Fill:**

- Product name:  
- Subtitle:  
- Pillar colour:  

### 2) Branding

```
This workbook is for South African women who [situation].

You will leave with:
• One clearer idea
• One practical skill
• One action you can take this week

FutureHer does not create noise. FutureHer creates readiness.
```

### 3) Table of contents

List sections only — max 8.

### 4) Workbook pages (repeat block)

For each section:

- Section title  
- 3–5 sentence teach  
- Prompt box (“Write here”)  
- Optional checkbox list  

Reuse episode frameworks — do not invent new IP weekly.

### 5) Action steps

Max 7 total. Each has:

- Action  
- Time estimate  
- Done checkbox  

### 6) QR codes

| QR | Destination |
|---|---|
| 1 | WhatsApp / Forward Collective invite |
| 2 | YouTube playlist for this pillar |
| Optional 3 | Newsletter |

Test every QR before export.

### 7) Upsell page (soft)

```
When you’re ready for the next layer:
• [Next product / challenge name] — [one line]
• Or stay close in The Forward Collective

No pressure. Readiness compounds.
```

### 8) Thank-you page

```
Thank you for investing in your future self.

You’re welcome forward.
— FutureHer
[contact / community]
```
