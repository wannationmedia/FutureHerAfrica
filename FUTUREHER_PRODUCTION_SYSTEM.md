# FutureHer — Solo Founder Production System

**Document status:** Production operating system (v1.2) — edit mechanics; craft defers to Design Studio  
**Operator model:** One founder · limited weekly hours · parallel tech company  
**Primary editor:** CapCut Pro (already owned)  
**Success metric:** One full content week packaged in **≤ 4 hours**  
**Creative authority (look/motion/colour/type):** `FUTUREHER_BRAND_DESIGN_STUDIO.md`  
**Phase 2 master (COO OS + 15 SOPs):** `FUTUREHER_OPERATING_SYSTEM.md`  
**Phase 5 pipeline (idea → publish):** `FUTUREHER_VIDEO_PRODUCTION_ENGINE.md`  
**Related:** `FUTUREHER_FOUNDATION_MANUAL.md` · `FUTUREHER_FOUNDING_STRATEGY.md` · `FUTUREHER_COMMUNITY_MEDIA_STRATEGY.md` · `FUTUREHER_CONTENT_INTELLIGENCE.md`

## 0. Design Law

| Law | Meaning |
|---|---|
| **Automation over perfectionism** | Templates decide 80% of look and pace. You only decide topic and teaching. |
| **One source → many outputs** | One 8-minute episode creates the entire week. Never create Shorts from scratch. |
| **Decide once, reuse forever** | Intro, outro, captions, lower thirds, music, CTAs, end screens are locked assets. |
| **Phone-first, template-first** | If it cannot be filmed and edited inside a known template, redesign the episode. |
| **Free / already-owned tools** | New paid tools only when they buy back ≥ 2 hours/month. |

**Editorial promise (unchanged):** FutureHer does not create noise. FutureHer creates readiness.

## 1. The 4-Hour Week

### 1.1 What “a week of content” means

From **one** long-form episode (default: **8-Minute Forward Format**):

| Asset | Count | How it is made |
|---|---|---|
| YouTube long-form | 1 | CapCut long-form template |
| YouTube Shorts | 5 | CapCut Shorts batch from same timeline markers |
| Instagram / Facebook Reels | 3 | Best 3 Shorts, Reels export preset |
| Thumbnail | 1 | CapCut / Canva Free template |
| Forward Notes draft | 1 | Script → paste into newsletter template |
| YouTube Community posts | 4–5 | Copy-paste from Community SOP pack |
| WhatsApp announcement + voice classroom note | 1 + 1 | Script CTA + 60–90s phone voice note |
| SEO pack | 1 | Title / description / tags / chapters checklist |

Deep cuts (12–20 min) are **optional** and count as a double week — only when the other company allows it.

### 1.2 Time budget (hard ceiling)

| Block | Minutes | Output |
|---|---|---|
| 0. Decide + brief | 15 | Episode brief filled |
| 1. Research sprint | 20 | 5 facts / examples / sources max |
| 2. Script (template) | 30 | Spoken script + Shorts markers |
| 3. Film / voice | 40 | A-roll (+ screen if needed) |
| 4. CapCut long-form | 45 | Finished master export |
| 5. CapCut Shorts + Reels | 40 | 5 Shorts + 3 Reels exported |
| 6. Thumbnail | 10 | 1280×720 locked |
| 7. SEO + upload + schedule | 25 | YouTube + Shorts queued |
| 8. Community pack | 15 | Community tab + WhatsApp + newsletter draft |
| **Total** | **~240** | Full week packaged |

If a block overruns, **cut scope** (fewer Shorts, no screen demo, shorter cold open) — never invent a new process mid-week.

### 1.3 Weekly calendar (solo-founder reality)

Do this as **one batch day** or two short blocks.

| Option | When | Pattern |
|---|---|---|
| **A — Single batch** | One weekend or weekday block | All 4 hours in one sitting |
| **B — Split** | 2× 2 hours | Hours 1–2: brief → film; Hours 3–4: CapCut → distribute |

Publishing can be **scheduled**, not live. Batch on Sunday → publish Mon–Fri automatically.

**Recommended publish skeleton**

| Day | Publish |
|---|---|
| Mon | Long-form premiere or upload + Community intention post |
| Tue–Sat | 1 Short/day (5 total) |
| Wed / Fri | 1–2 Reels (from Shorts set) |
| Midweek | Community question post |
| Fri | Forward Wins / challenge reminder |
| Sun | Soft next-episode preview |

### 2.2 Explicitly deferred (do not buy yet)

| Tool | Why wait |

| Descript | CapCut covers captions + cut for this system |

### 3.2 Long-form YouTube template (`FH_TMPL_Longform_8min`)

**Canvas:** 1920×1080 · 30fps  
**Target runtime:** ~8:00 (±60s)

| Timeline block | Duration | Locked? | Contents |
|---|---|---|---|
| Intro | 6–8s | Yes | `FH_TMPL_Intro_7s` compound clip |
| Cold open / hook | ~30s | Slot | A-roll placeholder |
| SA story beat | ~90s | Slot | A-roll + optional B-roll track |
| Problem explain | ~120s | Slot | A-roll + lower third “The real problem” |
| Skill teach | ~120s | Slot | A-roll / screen-record lane |
| Psychology beat | ~60s | Slot | A-roll + soft music lift |
| One action today | ~40s | Slot | On-screen numbered steps (max 3) |
| Community CTA | ~20s | Semi-locked | CTA compound + WhatsApp line |
| Next preview | ~10s | Slot | Talking-head teaser |
| Outro + end screen | 20–35s | Yes | `FH_TMPL_Outro_30s` + end screen elements |

**Locked style settings**

- Transitions: 240–400ms ease only (save as CapCut default)  
- Colour: one LUT / adjustment preset named `FH_Grade_Horizon` (see Design Studio §7.3 / `brand/03_colour/FH_Grade_Horizon_notes.md`)  
- Captions: auto-captions → apply `FH_TMPL_Captions_Style`  
- Lower thirds: attach `FH_TMPL_LowerThird` at name/framework moments  
- Music: bed track from `FH_ASSET_MusicBeds` at −24 to −30 dB under voice  
- Loudness: CapCut normalize / voice enhance once per project  

**One-click edit path**

1. Duplicate `FH_TMPL_Longform_8min` → rename `FH_YYYYMMDD_Slug`  
2. Drop A-roll into marked slots  
3. Auto captions → apply caption style  
4. Replace 3 text cards (framework name, action steps, CTA URL/handle)  
5. Export preset: `FH_YT_1080p`

### 3.3 Shorts template (`FH_TMPL_Shorts_9x16`)

**Engine (authority):** `operations/SHORTS/SHORTS_ENGINE.md`  
**Script template:** `templates/SHORTS_SCRIPT.md`  
**Benchmark:** SHORT S1 quality — human, conversational, emotionally intelligent, practical, premium, South African, hopeful.

**Canvas:** 1080×1920 · 30fps · **28–30s each** (formula-locked)

| Layer | Spec |
|---|---|
| Formula | HOOK 0–3 · REFRAME 3–10 · VALUE 10–22 · ACTION 22–30 · sign-off hold |
| Safe margins | Keep face + text inside centre 80% |
| Hook text | 0–3s, max 6 words, Stone/Ink — validate a real feeling |
| Captions | Burned in · large · high contrast · max ~6 words/card |
| Series tag | Small Lagoon/Brass/Clay/Ink pill top-left |
| FH mark | Bottom corner, low opacity or end hold |
| Motion | Subtle 5–8% zooms · premium 240–400ms transitions · no meme shake |
| Sign-off (locked) | “One step today. A different future tomorrow.” |
| CTA end card | Last 2s: “Full lesson on FutureHer” |
| Music | Short bed from asset pack, or silence under voice |

**Batch method**

1. Mark `S1`–`S5` on long-form; **rewrite each Short to the formula** (never ship raw long-form paste)  
2. Duplicate Shorts template ×5  
3. Paste / punch-in / re-VO to formula lines → reframe · subtle zoom on hook + action  
4. End CTA compound with official sign-off  
5. Export preset: `FH_Shorts_1080x1920`

### 3.4 Reels template (`FH_TMPL_Reels_9x16`)

Same as Shorts with **two differences only**:

1. End card CTA: Instagram/Facebook-safe (“Link in bio / Forward Collective”)  
2. Export filename prefix `FH_REEL_` for Meta Business Suite batch upload  

Pick the **best 3 of 5** Shorts — do not cut unique Reels.

### 3.5 Intro template (`FH_TMPL_Intro_7s`)

Per founding brand:

1. Soft Stone → Ink wash  
2. Horizon arc draws  
3. Wordmark **FutureHer**  
4. Tagline: *Ready for what’s next.*  
5. Optional 1.5s series colour flash + series name (after brand maturity)

Audio: logo sting ~1.2s from CapCut library (soft mallet / warm pad). **No whooshes** (Design Studio §18.3).

Export as compound clip / nested template used at start of every long-form.

### 3.6 Outro template (`FH_TMPL_Outro_30s`)

1. Recap strip: **Idea / Skill / Action** (3 text slots)  
2. Soft CTA: Subscribe + join **The Forward Collective**  
3. Hold FH mark 1–2s  
4. Hand off to end screen elements  

Tone: teacher closing class — never begging.

### 3.7 End screen template (`FH_TMPL_Endscreen`)

CapCut visual layout matching YouTube end-screen zones:

| Element | Placement |
|---|---|
| Subscribe reminder | Lower third or centre card (first 5–10s of outro window) |
| Video element placeholders | Left + right (you’ll map in YouTube Studio) |
| Community CTA line | “Join The Forward Collective — link in description” |

**YouTube Studio (not CapCut):** save channel default end screen: Subscribe + 2 videos (Best for viewer / playlist). CapCut only mirrors the visual so the cut feels intentional.

### 3.8 Captions style (`FH_TMPL_Captions_Style`)

| Property | Value |
|---|---|
| Font | Satoshi (fallback: IBM Plex Sans / Plus Jakarta Sans emergency) |
| Case | Sentence case |
| Words on screen | 3–6 |
| Colour | Ivory `#FFFCF8` on Ink chip @75–85%, or Ink on Stone |
| Accent | **One series accent** underline/keyword colour per video (registry §4.8) |
| Position | Lower-centre, above YouTube UI |
| Animation | Chunk fade 120–180ms — **no bounce, no pop** |

Apply once → CapCut “Apply to all”. Full sheet: Design Studio §10.4.

### 3.9 Lower thirds (`FH_TMPL_LowerThird`)

| Variant | Use |
|---|---|
| `LT_Name` | Founder name + role (first appearance) |
| `LT_Framework` | Named framework title |
| `LT_Series` | `FutureHer · Money` etc. |
| `LT_Step` | “Step 1 / 2 / 3” |

Design: thin Brass rule + Satoshi text on Stone or Ink panel. Max 2 lines. Animate **0.4s fade in · ~4s hold · 0.3s fade out** (Design Studio §9.5).

### 3.10 Background music pack (`FH_ASSET_MusicBeds`)

Inside CapCut, favourite 6 tracks max:

| Slot | Mood | Use |
|---|---|---|
| Bed A | Calm ambient | Default under teaching |
| Bed B | Slightly warmer | Story / psychology |
| Bed C | Light forward pulse | Action / demo |
| Short A/B/C | Energetic but clean | Shorts/Reels only |

Rules: duck under voice; never lyric-forward tracks; never tribal caricature; keep CapCut commercial license for YouTube.

### 3.11 Sound effects pack (`FH_ASSET_SFX`)

Favourite ≤ 8 sounds:

- Soft tick (list items)  
- Soft UI click (screen steps)  
- Paper / notebook (framework reveal)  
- Gentle success chime (action complete)  

Ban: whooshes, cartoon boings, meme impacts, airhorns.

### 3.12 CTA pack (`FH_ASSET_CTA_Pack`)

Pre-built CapCut text/compound clips:

1. Subscribe soft ask  
2. Forward Collective WhatsApp  
3. “One question for you…” (pin comment prompt visual)  
4. Shorts end: official sign-off + “Full lesson on FutureHer”  
5. Challenge reminder  

Swap URL/handle text once per month — not every episode.

### 3.13 Thumbnail template (`FH_TMPL_Thumbnail_1280x720`)

| Zone | Spec |
|---|---|
| Size | 1280×720 |
| Face | Left or right third, consistent framing |
| Title | Max 4–6 words, sentence case |
| Series pill | One accent from Design Studio §4.8 registry (Systems = Lagoon; Build = Clay + Brass rule) |
| FH mark | Corner, clear space |
| Background | Soft grade, Stone panel or negative space — no collage |

**CapCut path:** export still from best talking-head frame → overlay text template.  
**Canva Free path:** duplicate brand thumbnail file → swap photo + 4–6 words.

## 4. One-Click Workflows

“One-click” here means **one duplicate + replace**, not literal magic. Each workflow has a single happy path.

### 4.1 Weekly Master Workflow (the only one you need)

```
Problem Bank pick
    → Fill Episode Brief (15m)
    → Script Template with Shorts markers (30m)
    → Film A-roll in one take-ish (40m)
    → Duplicate Long-form CapCut template
    → Drop footage + auto captions + export
    → Duplicate Shorts template ×5 from markers
    → Thumbnail template
    → YouTube upload checklist (schedule week)
    → Paste Community pack
```

### 4.2 CapCut “Replace Media” habit

Always:

1. Duplicate template project  
2. Replace media in placeholder clips  
3. Regenerate captions  
4. Export using saved preset  

Never rebuild timelines weekly.

### 4.3 Atomization workflow (forced order)

1. Finish long-form first  
2. Export Shorts from marked segments only  
3. Choose top 3 → Reels filenames  
4. Thumbnail last (use strongest emotional frame)  
5. SEO pack from script header  
6. Community pack from brief fields 7–9  

### 4.4 Publish automation (free)

| Platform | Automation |
|---|---|
| YouTube long-form | Schedule in Studio |
| YouTube Shorts | Schedule 1/day |
| Reels / FB | Meta Business Suite schedule |
| Community tab | Batch-write in Docs; paste on publish days (2 min/day) |
| WhatsApp | Announcement channel only; pre-write text Sunday |
| Email | Schedule newsletter for Monday or episode day |

## 6. SOPs (with checklists)

Copy blank templates from `/templates`. Run checklists in order. Tick every box or explicitly skip.

---

### SOP 01 — Research (20 minutes)

**Goal:** Enough truth to teach. Not a dissertation.

**Inputs:** Problem Bank, YouTube comments, WhatsApp Ask Forward, your lived SA context  
**Output:** 5 bullets max in the brief

#### Checklist

- [ ] Pull top unanswered question from Problem Bank (Friday list)  
- [ ] Write the **problem sentence** in her exact words  
- [ ] Confirm pillar (AI / Career / Money / Build / Soft Power / Mind OS)  
- [ ] Confirm series tag + accent colour  
- [ ] Gather ≤ 5 supporting points (examples, SA context, one myth to kill)  
- [ ] Note 1 phone-first action she can do in < 30 minutes  
- [ ] Note psychology beat in one sentence (support only — not clinical)  
- [ ] Skip anything that needs original data collection this week  
- [ ] Stop at 20 minutes even if “more research would be nice”

**Research sources (free only)**

1. Your Problem Bank  
2. YouTube autocomplete + People also ask (for phrasing, not for copying)  
3. Comments on your last 3 videos  
4. WhatsApp / Facebook questions  
5. Official docs for tools you demo (when AI/digital episode)

---

### SOP 02 — Script Writing (30 minutes)

**Goal:** Speakable teaching script for the 8-Minute Forward Format.

**Output:** Filled `templates/SCRIPT_8MIN.md` with Shorts markers `S1`–`S5`

#### Checklist

- [ ] Copy script template → episode folder  
- [ ] Fill Idea / Skill / Action at the top before prose  
- [ ] Write hook (0:00) in her language — no channel trailer energy  
- [ ] Write SA story beat (authentic, not caricature)  
- [ ] Explain problem simply  
- [ ] Teach skill in ≤ 3 steps  
- [ ] Add psychology beat (why it works / remove shame)  
- [ ] One action today (single step)  
- [ ] Community question (meaningful — not “Did you like this?”)  
- [ ] Community challenge line  
- [ ] Next episode preview (one sentence)  
- [ ] Mark 5 Shorts moments inline: `[S1]` … `[S5]`  
- [ ] Read aloud once; cut any sentence you trip on  
- [ ] Hard stop at 30 minutes — film with “good enough”

**Script rules**

- Conversational SA English  
- No American hype cadence  
- Max one framework name per episode  
- Affiliate/tool mentions only if taught for real  

---

### SOP 03 — Voice Generation / Recording (40 minutes)

**Primary method:** Founder voice (trust asset).  
**“Voice generation” in this system means:** generate a clean spoken performance fast — not synthetic celebrity voices.

#### A. Default — record yourself

##### Checklist

- [ ] Quiet room; phone horizontal or vertical per format plan (long-form horizontal preferred)  
- [ ] Mic 15–20 cm; same shirt/background as brand normal  
- [ ] Soft daylight or one LED; face evenly lit  
- [ ] Teleprompter option: Google Docs big text / CapCut teleprompter / printed script  
- [ ] Record cold open separately if energy is better (optional)  
- [ ] Prefer longer takes with pauses over 40 micro-clips  
- [ ] Clap or verbal slate: `FH [slug] take 1`  
- [ ] Capture 3–5 B-roll clips only if essential (hands, screen, notebook)  
- [ ] Screen record demo in one pass (tool episodes)  
- [ ] Backup file to episode `03_footage/`  

#### B. Optional — CapCut text-to-speech (rare)

Use only for:

- Accessibility alt cuts  
- Temporary drafts when voice is unavailable  

Never as the default channel voice.

##### Checklist (if used)

- [ ] CapCut TTS voice: calm, clear, neutral — test 10 seconds first  
- [ ] Rewrite script shorter; TTS hates long clauses  
- [ ] Disclose nothing fake as “live teaching” if it would break trust  
- [ ] Prefer returning to founder voice next episode  

#### C. CapCut voice cleanup (2 minutes)

- [ ] Apply voice enhance / denoise  
- [ ] Normalize loudness  
- [ ] Remove mouth clicks only if obvious

### SOP 06 — SEO (15 minutes inside upload block)

**Goal:** Findable by the woman with the problem — not keyword spam.

##### Checklist

- [ ] **Title:** Outcome + truth (+ SA when natural). ≤ ~60–70 chars preferred  
- [ ] **Thumbnail text ≠ full title** (complement, don’t duplicate paragraph)  
- [ ] **Description block 1 (first 2 lines):** problem + promise + CTA to Forward Collective  
- [ ] Paste timestamps/chapters from script sections  
- [ ] Paste links: WhatsApp / newsletter / challenge  
- [ ] **Tags:** 8–15 relevant phrases (pillar + problem + “South Africa” when true)  
- [ ] Playlist: add to correct series playlist (`FH Money`, etc.)  
- [ ] Category: Education  
- [ ] Language / caption certify: English (SA)  
- [ ] Alternate title ideas logged for A/B later (optional note)  

**Free SEO method**

1. Type problem into YouTube search — note autocomplete  
2. Use her words from Problem Bank in title/first line  
3. Chapters improve session time (retention SEO)  
4. Shorts titles = hook phrase, not full lecture title

- [ ] Move CapCut project to episode note or Drive

### SOP 08 — Community Posts (15 minutes batch write)

Write all posts on batch day. Publish takes 2 minutes on the day.

#### Monday — Week intention

- [ ] 1–2 sentences: this week’s skill  
- [ ] Soft invite: challenge / Forward Collective  
- [ ] No link spam wall  

#### Midweek — Amplify a member

- [ ] Quote or paraphrase one comment/question (permission if personal story)  
- [ ] Teach one line further  
- [ ] Point to episode  

#### Challenge day

- [ ] Reminder of this month’s challenge action  
- [ ] Ask for a completion emoji/comment — not shame  

#### Friday — Forward Wins

- [ ] Celebrate one win (member or founder micro-win)  
- [ ] Keep premium tone — no hustle flex  

#### Weekend — Preview

- [ ] One-line next episode tease  
- [ ] Series continuity  

#### WhatsApp Announcement (episode day)

- [ ] Problem sentence  
- [ ] Link to YouTube  
- [ ] Reminder of Voice Classroom note  

#### Voice Classroom (60–90s)
